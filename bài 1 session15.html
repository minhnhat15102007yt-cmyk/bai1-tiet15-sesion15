Phần 1: 3 hậu quả Nam gặp phải

  1. Mất dữ liệu vĩnh viễn: Lưu đè (Ctrl+S) trên máy cá nhân khiến code bay màu không có cách khôi phục.

  2. Loạn phiên bản (Version Hell): Đặt tên file thủ công (v1, v2_final) gây nhầm lẫn, không biết đâu là bản chuẩn.

  3. Đứt gãy làm nhóm: Gửi file qua Zalo dễ dẫn đến xung đột code, không đồng bộ được tiến độ với đội “Smart Food”.

Phần 2: Quy trình Hybrid Workflow (Khôi phục 1-click)

  1. Dùng Git quản lý cục bộ: Chỉ giữ 1 file main.py, dùng lệnh git commit để ghi lại lịch sử thay đổi. Thích quay lại bản cũ lúc nào chỉ cần 1-click.

  2. Đẩy lên GitHub: Đồng bộ code lên mây để phòng hờ hỏng máy, mất dữ liệu.

  3. Bật Version History trên Cloud (OneDrive/Google Drive): Đặt thư mục code vào OneDrive/Google Drive. Nếu lỡ lưu đè nhầm, chỉ cần vào web chọn lịch sử phiên bản rồi bấm Restore là xong.
